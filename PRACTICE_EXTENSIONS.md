# Practice Extensions

Attempt these after studying the matching demonstration. Start with a dry run and test edge cases.

## Number operations
1. Check whether a number is a strong number.
2. Print all prime numbers in a given range.
3. Find the largest and second-largest digits.
4. Check whether a number is a perfect square.
5. Print the factors of a number.
6. Convert decimal to binary using repeated division.
7. Find the HCF of multiple numbers.

## Patterns
1. Right-angled triangle of stars.
2. Inverted right-angled triangle.
3. Number triangle.
4. Floyd's triangle.
5. Pyramid and inverted pyramid.
6. Hollow square.
7. Diamond pattern.
8. Pascal's triangle (extension).

## Arrays and strings
1. Find the second-largest distinct element.
2. Rotate an array left or right by `k` positions.
3. Merge two sorted arrays.
4. Remove duplicate elements.
5. Check whether two strings are anagrams.
6. Count words, spaces, digits and special characters.
7. Find the first non-repeating character.

## Pointers and functions
1. Swap two values using pointers.
2. Find the length of a string using pointer traversal.
3. Pass an array and its size to a function.
4. Return multiple results through pointer parameters.
5. Demonstrate `const` with pointer parameters.

## Data structures and other essentials
1. Implement a linear queue, then compare it with a circular queue.
2. Implement a stack-based parenthesis checker.
3. Store and search student records using structures.
4. Write records to a text file and read them back.
5. Dynamically allocate an array and resize it safely.
