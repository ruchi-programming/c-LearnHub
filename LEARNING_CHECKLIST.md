# Learning Checklist

Use this checklist to track concepts demonstrated and practised.

## Core C
- [ ] Program structure and `main()`
- [ ] Header files and comments
- [ ] Variables, constants and data types
- [ ] `printf()` and `scanf()` return-value checking
- [ ] Type conversion and format specifiers
- [ ] Arithmetic, relational, logical and assignment operators
- [ ] `if`, `if-else`, nested conditions and `switch`
- [ ] `for`, `while`, `do-while`, `break` and `continue`
- [ ] Functions, parameters, return values and scope

## Problem solving
- [ ] Digit count, digit sum and reverse
- [ ] Palindrome number
- [ ] Armstrong number
- [ ] Prime and perfect number
- [ ] GCD and LCM
- [ ] Nested-loop patterns

## Data structures and memory
- [ ] 1D arrays and traversal
- [ ] Searching and sorting
- [ ] Insertion and deletion by shifting
- [ ] 2D arrays and matrix operations
- [ ] Strings and `'\0'`
- [ ] Pointer declaration, address and dereferencing
- [ ] Pointers as function parameters
- [ ] Structures and arrays of structures
- [ ] Stack using a fixed-size array
- [ ] Circular queue using a fixed-size array
- [ ] Stack/queue overflow and underflow conditions

## Beyond the basics
- [ ] Recursion and call stack
- [ ] Dynamic memory: `malloc`, `calloc`, `realloc`, `free`
- [ ] File handling: `fopen`, `fprintf`, `fscanf`, `fgets`, `fclose`
- [ ] Preprocessor directives and macros
- [ ] `enum`, `typedef` and `const`
- [ ] Bitwise operators
- [ ] Command-line arguments
- [ ] Header/source file separation and multi-file compilation
